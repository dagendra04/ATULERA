ℹ️ Supabase Integration Notes

This app currently uses SQLite for local storage. To connect Supabase:

  1. Install: pip install supabase
  2. Create tables in Supabase matching: services, service_requests, inquiries, faqs
  3. Add SUPABASE_URL and SUPABASE_KEY to your environment
  4. Replace get_db() calls in app.py with Supabase client queries

Contact us or check README.md for full migration instructions.
